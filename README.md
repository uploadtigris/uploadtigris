### 🧑🏻‍💻 About me

I troubleshoot networks for a living and build them for fun. As an IT Support Associate at Amazon I support 5,000+ users, and the tickets I like best are the network ones: VPN routing conflicts, DNS failures, devices that can't find their domain.

At home I run a 10" rack with a pfSense firewall, a managed PoE switch, a Wi-Fi access point and a Pi-hole DNS server. This month I'm segmenting it into five VLANs with default-deny firewall rules, and I write up every problem I fix so I only solve it once.

💼 **Looking for:** entry-level network technician, NOC or network support roles in Austin, TX or remote.

### 🔧 Homelab

Status means what it says: **running** is live today, **in progress** is being built this month, **planned** is designed but not started.

| Area | What | Status |
|---|---|---|
| Routing & firewall | pfSense routing and firewalling the home network | ![running](https://img.shields.io/badge/running-2E7D32) |
| DNS | Pi-hole filtering DNS for every device | ![running](https://img.shields.io/badge/running-2E7D32) |
| Segmentation | 5 VLANs (Mgmt, Trusted, IoT, Guest, Servers) on pfSense + GS308EP switch, 10.0.VLAN.0/24 | ![in progress](https://img.shields.io/badge/in%20progress-F9A825) |
| Firewall policy | Default deny between VLANs, documented exceptions, tested with nmap | ![in progress](https://img.shields.io/badge/in%20progress-F9A825) |
| DHCP | Per-VLAN DHCP scopes on pfSense | ![in progress](https://img.shields.io/badge/in%20progress-F9A825) |
| Wireless | One SSID per VLAN on a TP-Link EAP610 (Guest SSID already live) | ![in progress](https://img.shields.io/badge/in%20progress-F9A825) |
| Documentation | Diagrams, IP plan, port map, troubleshooting write-ups | ![in progress](https://img.shields.io/badge/in%20progress-F9A825) |
| Monitoring | LibreNMS + SNMP on the switch and firewall | ![planned](https://img.shields.io/badge/planned-757575) |
| Power | UPS with NUT for graceful shutdown | ![planned](https://img.shields.io/badge/planned-757575) |
| Logging & SIEM | Wazuh rebuild with pfSense syslog | ![planned](https://img.shields.io/badge/planned-757575) |
| Services | NextCloud on the Servers VLAN | ![planned](https://img.shields.io/badge/planned-757575) |
| Remote access | WireGuard VPN into the lab | ![planned](https://img.shields.io/badge/planned-757575) |
